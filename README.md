# Cloverdale Paint Dashboard

Interactive social media dashboard demo for Cloverdale Paint: Instagram, Facebook, LinkedIn, YouTube and GA4.

Live demo: https://tjsuduku.github.io/cloverdale-paint-dashboard/

- Growth scale, top content and per-platform deep dives
- Competitor benchmark
- Zoomable audience geography map
- Report builder (bi-weekly, monthly, custom; PDF)
- Built-in chat assistant that answers questions from the data

Data snapshot: Jun 26 – Sep 23, 2026. Works on desktop and phone.
